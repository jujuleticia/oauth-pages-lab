# Laboratório de autenticação — Cloudflare Pages + Google + GitHub

Projeto preparado conforme o enunciado da Avaliação 2. O projeto não usa Node.js, npm, npx, Wrangler, package.json ou dependências externas.

## Antes da implantação
1. Crie o repositório GitHub e envie `public/`, `functions/` e `entrega1/`.
2. Publique pelo Cloudflare Pages com Framework preset None, Build command vazio e Build output `public`.
3. Crie o D1 e execute o esquema indicado no enunciado.
4. Crie o binding `DB` no Pages.
5. Cadastre as credenciais Google/GitHub como variáveis e segredos criptografados.
6. Substitua os placeholders da pasta `entrega1/` pelos dados/evidências reais.

## Segurança
Nunca coloque Client Secrets, tokens, cookies, state, nonce ou code_verifier no repositório ou nas evidências.
